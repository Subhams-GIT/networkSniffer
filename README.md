2. if selects to examine a file then examines and shows the data in tabular form.
3. if selects to examine incoming packets then the packets are captured and saved onto a custom file location
4. show the network data by packet filtering in table
5. analyse a particular packet

- IPv4/IPv6 header\
- TCP/UDP header\
- ICMP types\
- Raw payload view
